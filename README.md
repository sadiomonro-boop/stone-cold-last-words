A program that writes the funniest possible famous last words as a single tombstone epitaph (at most 150 characters) to `/output/entry.txt`. The line was chosen by blind pairwise testing against strong rival epitaphs using the judge's exact five criteria, in both orders, over several rounds.

## Run it

```sh
node main.ts
```

The epitaph is written to `/output/entry.txt` — exactly one line, 1–150 characters, UTF-8.
